# PaperDock：先走通，再选风格

状态：用户本轮接受现有原型其余行为；新增默认随机、自定义固定/入随机规则同步后待核验。A/B/C 未选款，正式用例基线未独立审查，未授权开发 Mac 软件。此文档不替代需求与正式用例。

原型：`prototype/paperdock.prototype.html`，单文件、无依赖，仅内存示例。刷新会重置便签、新建模式、随机池、自定义颜色和本次风格选择；界面上的更新提示不代表真实本地保存。不要输入需要保留的资料。

## 1. 先用同一条工作链路讨论

```text
工作中想到“明天联系客户确认报价”
  → 模拟桌面：点击或拖出边缘便签
  → 输入正文，自动生成“明天联系客”
  → 集中管理：正文追加“核对 40HQ 价格”，补充待办、改标题
  → 收纳桌面便签〔关闭即收纳：产品反馈已接受〕
  → 搜索正文“40HQ”，找回已收纳记录
  → 显示到桌面，继续修改
  → 按最后修改日期回到今天分组
```

原型顶部“用户故事走查”提供 S01—S08 场景入口。开始场景后，当前步骤持续显示在工作区上方，不需要记住关闭弹层前的说明；不自动把体验标成通过。切换场景会重置便签示例，新建模式、随机池、自定义颜色和界面风格保留至本次刷新前；面板有重置说明，连续切换另有确认。

优先讨论三个实际问题：
1. 记录一闪念时，边缘新建和备用“新建便签”入口是否容易找到？
2. 收纳后，从集中列表到全文搜索再回桌面是否顺手？
3. 手动标题、待办和按修改日期迁组是否符合找回记录的习惯？

这些现有流程用户已表示无其他修改，不再重新征询；本轮只更新新建配色，不以此推断 A/B/C 已选款。

## 2. 三种候选：共享内容，真正改变阅读方式

在“风格讨论”中直接切换，便签内容、纸色、搜索条件和已选择记录不变。也可以用页面 URL 的 `?variant=A`、`?variant=B`、`?variant=C` 分别打开候选；这是初始化预览入口，不是持久化设置。当前候选会显示在工作区上方。

| 候选（均未批准） | 实际可见差别 | 适合讨论什么 | 取舍 |
| --- | --- | --- | --- |
| A · 原生书桌 | 178px 常规侧栏，列表和编辑器均衡三栏，系统无衬线字体，低装饰选中态 | 经常边找边改的人，能否迅速进入内容 | 密度与摘要展示折中；只是偏 Mac 工具的网页视觉，不是原生控件 |
| B · 纸本档案 | 150px 侧栏，紧凑日期条目，日期下横线，条目少留白，品牌与条目标题用衬线字体 | 更看重按日期回顾、一次扫过更多记录的人 | 同屏目录更密，长摘要仍单行，视觉更像档案而非卡片 |
| C · 轻卡片 | 80px 窄导航，较宽列表，独立圆角卡片，正文摘要最多两行，状态更醒目 | 标题相近时，能否靠摘要和状态辨认 | 每张占用更多高度，导航更紧凑；深色纸色不会自动换成紫色 |

三者只改变必要的导航宽度、列表密度、标题字体和摘要层级，不另造三套流程，也没有换掉整页结构。窄屏统一上下堆叠，方便浏览器查看；正式目标仍是 Mac 本地软件，不由此扩展移动端范围。

**当前建议，未批准**：先以 A 作为流程评审的中性基线；若主要靠日期扫读再比较 B；若主要靠摘要找记录再比较 C。没有浏览器独立视觉结果前，不宣称哪种更好。

## 3. 纸色在流程之后讨论

六种沿用纸色，作为默认随机池（产品反馈接受；无医学效果承诺）：

| 名称 | 背景色 | 用途仅为视觉选择 |
| --- | --- | --- |
| 纸白 | `#FFFEFA` | 明亮中性 |
| 暖米 | `#F5EEDC` | 默认随机池成员之一，不再是唯一新建默认色 |
| 羊皮纸 | `#E9DDC6` | 更暖、更深 |
| 浅灰 | `#EDF0ED` | 低彩中性 |
| 淡绿 | `#E5EEDC` | 轻微绿色倾向 |
| 深灰 | `#303731` | 深底浅字 |

用户本轮已确认：**选色盘为主入口，色号只作可选辅助**。不懂色号也应通过点选/拖动调整颜色明暗并实时预览；不再要求用户重选这一操作方向。原型采用大幅二维浓淡/明暗色盘＋色相滑条，精确视觉形式仍为候选；Tab/方向键也能完成选色。

```text
新建默认从六色池随机（允许重复）
  → 打开便签纸色 / 设置中的新建配色
  → 点拖色盘＋色相条；色号辅助可选
  → 选择范围（此时都只是草稿）
  ├→ 只改当前：不改新建模式，也不自动加入随机池
  ├→ 以后固定：所有入口之后新建用此色，旧便签不变
  └→ 加入随机：颜色去重入池并切回随机，旧便签不变
       设置可不勾加入预览色，仅切回原随机池，保留以前加入的颜色
  → 点击应用才生效；取消/关闭/Esc 不留颜色、模式或池草稿
```

文字在纯黑与纯白之间按计算对比度选更清晰的一种。弹层展示计算值，但这不等于完整可访问性验收，更不作护眼或医学效果承诺。辅助色号采用六位十六进制格式，可留空；无效输入会提示，可清空或在色盘重选后继续应用。色盘中的渐变仅是选色工具，不是渐变纸张功能；未实现透明色、渐变纸色、主题导入、导出或真实存储。

## 4. 本轮决定与保留边界

用户原话“其他的没有什么要修改得了”：关闭即收纳、回收站恢复为收纳、内容日期策略、空白保留、标题取字、搜索中保留编辑对象、网页内备用入口均沿用，不再重复要求用户确认。

本轮只替换新建配色规则：默认六色随机，自己的颜色可只改单张、以后固定或主动加入随机。加入随机会去重并切回随机；设置可切回原池，保留此前已加入自定义色。所有模式只影响之后新建，旧便签的颜色、正文及修改日期不动。应用前只是草稿；取消丢弃新颜色、模式和池变化。

可点入口：便签“纸色”中三种范围；“设置与默认纸色”中的“选色并固定使用”和“随机配色设置”。后者可不勾“将预览颜色加入随机池”，仅切回既有池；这是避免无意添加预览颜色的最小交互。

A/B/C 仍未选款。正式原生能力、本地保存、退出恢复、全局快捷键与正式用例审查不是本次反馈可证明的结果，产品反馈接受不等于正式开发授权。

## 5. 本轮交付与核验边界

本轮沿基线局部完善：
- 修复搜索中编辑使选中记录跳转、下一次输入可能写到别张便签的风险：内容变化保留编辑对象，编辑器显式绑定记录 ID，筛出结果后给出说明。
- 正文和待办文字更新后，标题提示、日期与列表及时刷新；手动标题的空白判断一致。
- 新增持续用户故事导览；桌面可见便签统一标注置顶示意，不增加“可见但不置顶”的第三状态。收纳、删除恢复和配色预览取消现已获产品反馈接受，历史失败与验证边界继续保留。
- 便签拖动/缩放在当前页面内保留几何信息；初次显示、切换、浏览器视口变化和缩放结束时约束尺寸/位置，确保操作区留在模拟桌面内。深色便签按钮使用透明底、继承文字色，避免白字白底。切回集中管理不冒充保存到磁盘。
- 三种风格强化为不同信息密度与阅读层级，而非只切颜色；重置示例/空状态之前说明会丢弃当前便签内存并询问。
