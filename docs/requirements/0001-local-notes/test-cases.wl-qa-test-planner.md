# 用例 0001：本地便签产品评审

## 范围、入口与公共准备

**最新阶段**：用户本轮已批准方案v0.2，明确A三栏、当前Mac单屏普通窗口，并授权正式开发与独立验收。G1–G4步骤修正已独立复核闭合（见独立审查“最终文档复核”）；ready表示预期可执行，不表示运行通过。下文原型入口保留作交互依据，正式应用入口映射及不适用原型重置/B-C比较由独立验收计划单独说明，不重写业务预期。所有原生业务条目须在正式冻结版本重验；真人IME/跨应用证据与程序操作分开记。

[需求阅读页 v0.3](requirement.wl-req-confirm.html) / [需求唯一正文](requirement.wl-req-confirm.md)。产品已批准，独立审查已提出G1–G4，本版原位补齐待复核，见[独立审查](../../native-readiness-review.md)。R/P/Q保留历史编号；旧“建议/候选”指现有已接受规则，不重开产品决策。只授权方案与隔离实验，本文不是执行结果或正式实施批准。

**入口性质**：[本机目标原型](../../../prototype/paperdock.prototype.html)仅用于隔离示例体验，不是正式软件测试入口。正式 Mac 软件入口待补齐，原生与持久化验收不能以网页替代。分组中的片段链接只定位元素，不负责打开弹层/隐藏面板，仍按步骤点按钮。

**公共准备（仅原型步骤）**：本机浏览器的独立示例页面，无账号、无真实资料；原型刷新重置，不保存需要保留的数据。每条用例开始刷新，再点“重置示例”，在重置确认框点确认后继续；若该条明确点“重置为首次使用空状态”，同样须确认后才进入空状态，不停留在弹窗。颜色回滚检查必须刷新，不能只点重置示例（其保留本次新建模式、随机池、自定义颜色和风格）。各条独立执行、不沿用上一条数据。以下日期为相对执行日 D，不能把示例日期当成固定业务日期；无需修改系统时钟。

**数据集**：原型示例“客户报价跟进”含正文“明天联系客户确认报价。上海 → 德班，核对 40HQ 价格后再回复。”和两条待办；“便签产品的想法”位于 D-1；“项目复盘”位于 D-7；“周末想去的地方”已收纳。均为示例，不是真实客户数据。用例另输入的文字是合成数据。

**原生准备与权限**：TC-001/4、TC-010/4、TC-014用已提供的原生实验/未来正式入口与独立目录；记录版本、数据路径及PID，不刷新网页或重置待读回样本。实验只证明已有能力，未实现的管理/搜索不能算通过；正式软件需映射入口重跑。只可正常退出自身实例；不改权限、不注入全局键鼠、不操作日常资料。程序自驱与真人交互分开记，缺证据即未验。结束关闭自己页面/应用，保留合成证据。

**执行顺序**：原型步骤各自重置；原生步骤遵循上述独立准备，退出重开同目录，不套用网页刷新。

**执行记录约定**：仅引用[统一记录约定](../../../../AICodingBank/tools/execution-profiles/test-execution.md)，生成阶段不创建执行轮次或填结果。
