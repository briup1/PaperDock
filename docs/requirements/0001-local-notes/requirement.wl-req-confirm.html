SEC 06 / 11

用户故事

  • US01：As a Mac 使用者, I want 从屏幕边缘拖出独立便签并置顶记录, so that 不打断手头工作也能留下闪念。R01/R02；原型桌面。
  • US02：As a 记录者, I want 不命名也能靠标题与摘要辨认，必要时手动命名, so that 快速区分内容且保留自己的命名。R03；管理入口。
  • US03：As a 回顾者, I want 按最近修改分组并搜索标题与全文，含收纳, so that 记不清放在哪里也能找回。R04/R05；搜索入口。
  • US04：As a 办事者, I want 在文字便签里管理待办, so that 记录能变成可完成的行动。R06；编辑入口。
  • US05：As a 阅读便签的人, I want 选择内置或自定义纸色, so that 按个人偏好阅读内容。R07；配色入口。本轮随机/固定/单张与取消规则见 P02，产品方向已接受。
  • US06：As a 整理桌面的人, I want 收纳后仍能在管理处找回, so that 清理桌面不等于丢记录。R02/R05；管理入口。删除恢复 P04 已获本轮其余行为接受。
  • US07：As a 首次或暂未找到内容的人, I want 知道当前为空及下一步入口, so that 能开始记录或继续找回。P05，已获本轮产品反馈接受；空状态入口。

已确认规则

确认依据均为 E01 的对话摘要，不冒充逐字原对话或本稿整体批准。

  • R01：目标为 Mac 本地使用。只读网页原型不是最终软件，本地保存与退出恢复尚未实现（细节 Q07）。
  • R02：参考边缘拖出新建、独立便签、普通窗口置顶以及可见/收纳；所有便签可集中管理。这里的置顶指目标中的普通应用窗口前可见，原型无法验证系统层行为；具体范围 Q08。
  • R03：未手动命名时，以正文前 5 个可见字符自动命名；不足 5 字全显。可手动命名，正文后续变化不能覆盖手动标题；集中列表提供正文摘要以辨认。可见字符细则与清空手动标题见 Q01。
  • R04：集中列表按最后修改时间分组，不按创建日期。现有原型的内容修改动作、本地日期与倒序行为已获产品反馈接受；原生跨日验收边界见 Q02。
  • R05：支持标题及正文全文文字检索，范围包含已收纳便签。全文不等于只搜列表截断摘要；大小写、待办文字及筛选组合见 Q03。
  • R06：第一版保留文字与待办，用户已对先前第 3 条范围建议回答“同意”，不再重复询问范围。待办操作细节按 Q06 评审。
  • R07：提供常见阅读软件风格的内置纸色及自定义颜色；用户本轮确认以可视化选色盘为主入口，点选/拖动调整颜色与明暗并实时预览，不懂或不输入色号也能完成选色，色号输入仅为可选辅助并与选色盘联动（E04）。不作护眼疗效承诺；二维色盘、色相条等精确视觉形式仍为候选，本轮新建随机/固定/单张及取消规则见 P02（E05），精确界面仍为原型实现，不等于正式设计批准。
