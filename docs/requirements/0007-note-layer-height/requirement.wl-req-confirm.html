SEC 03 / 09

需求重定义

最终目标
少遮挡，但需要时仍可读写；在管理页面统一设置便签打开高度，逐张决定沉底或浮顶。
路径判断
用户最新设置规则比“每张旧尺寸减半一次”更直接、可调整，因此撤销旧减半方案。在已核验范围内暂未发现更简单且满足统一高度及按张层级的替代路径；小高度可达性和真实遮挡须补运行证据。
范围
当前本机macOS、同一桌面空间的普通应用窗口；不保证全屏、其他Space、Stage Manager、系统弹窗及新增多屏策略。

SEC 06 / 09

业务规则

  • R01：折叠且锁定时保留标题、解锁和必要保存错误提示，隐藏＋、×、层级操作；解锁恢复。钉住仍锁整张，不能靠隐藏按钮代替最终拒绝。
  • R02：“设置与默认纸色”提供完整全局“便签高度（pt）”输入、保存、生效值与反馈，列表顶部移除该区；默认190pt仅用于新数据／缺字段，已有保存高度原值保留，允许小数且精确保留保存值；真实系统外框允许≤1pt对齐误差，不据此放宽输入范围。委托下采用推荐范围175…1000pt：下限服务小布局可达，上限避免无意义大面积遮挡；超屏时按可见区暂时限制显示并保持入口可访问，不改已保存设置、不改系统设置。无效、空、NaN、无限、越界一律拒绝且可见提示。保存失败保留旧生效值和草稿，成功才生效。
  • R02续：每次新建、重新打开、收纳找回及启动恢复使用当前设置高度；已打开窗口保存设置后不立即跳动。折叠条仍27pt，下次展开也使用当时设置。手动缩放只影响本次打开，不能覆盖全局值。旧锁定便签打开也用设置高度，但锁、宽、x和上沿保持（屏外可访问限制除外）；内容、ID、纸色不变。不批量重写旧尺寸、不做一次性减半或升级备份。
  • R03：每张分别保存两档层级。浮顶时只显示“沉底”，沉底时只显示“浮顶”；未锁展开／折叠都可切换，已锁先解锁。新建及缺新状态的旧记录默认浮顶。沉底仍桌面可见且在普通应用下方，不是收纳、删除或Dock最小化；点击编辑、管理器找回及重启不自动浮顶。只有明确切换才改变层级；失败保留原状态并可见报错。
  • R04：默认未固定且未加自定义色时六色每次等概率独立抽取，允许相邻重复，不轮换；保留固定色、加入池、暂存色及旧纸色，不主动重置、不重新染色。
  • R05：高度设置和整理／层级动作不改变内容修改时间，正文／标题／待办仍按现有规则更新。保留输入法未确认文本保护、保存失败保留已确认内容和退出失败阻止退出。
  • R06：compact固定工具栏＋中间滚动标题／正文／待办／错误＋下沿固定添加入口；每次新增自动滚入新行并聚焦输入。字号、待办增删改勾选、管理器布局和最终锁校验保持；有未确认输入法候选时不追加、不抢焦点，提示先确认或取消。错误与重试仍须可达。
