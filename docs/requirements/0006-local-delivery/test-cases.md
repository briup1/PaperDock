# 改动开发与本地交付用例 · 版本 2

规则来源：[需求 0006](requirement.wl-req-confirm.md)。这里只验证两部分流程，不重复便签功能用例。所有写入在临时 Git 仓库、临时安装目录或项目独占隔离库完成；不得对用户正在使用的实例执行退出、替换或数据写入。

## A 交接和 Git 范围

- TC01（R01、R02）：临时仓库 README.md 已改，unrelated.txt 另行暂存。对 README 取指纹两次，预期相同；无关暂存内容完全保留。修改 README 后指纹应变化。
- TC02（R01）：未选定的 app/Sources/Example.swift 修改，预期交接被拒绝，不能把未选源码编入交付。显式选定删除某源码、新增字面文件名 [note].txt 均能正确记录。
- TC03（R02）：传入 ../README.md、目录 app、绝对文件名或软链，预期拒绝；不得递归暂存。
- TC04（R01）：取指纹并完成交接后再次修改 README，执行交付预期停止，不提交、不安装。
- TC05（R02）：选定文件部分暂存、部分未暂存，预期交付停止，不改写用户选定块。
- TC06（R02）：README 交付、unrelated.txt 暂存；模拟构建/启动成功。预期本次提交只有 README，无关暂存仍保留；安装版本对应 HEAD。数据文件内容不变。

## B 构建、安装和恢复

- TC07（R03、R06）：交接后注入构建失败，预期 HEAD 不变、无安装、不清理旧包。
- TC08（R04）：唯一旧实例 PID=42，未显式传 42 时拒绝；传 42 可核对；再出现 PID=43 时即使传 42 也拒绝，不退出其他实例。
- TC09（R04、R06）：已有旧应用，模拟新版启动退出码 1；预期代码可已提交，保留临时 previous.app 和旧 ZIP，不宣称完成、不自动回退数据。
- TC10（R04）：同时获取两个交付锁，预期第二个立即拒绝，不并行安装。
- TC11（R04、R06）：编译真实 AppKit helper，查询当前应用只读信息；另在新独占库启动本轮构建，预期 helper 能辨识路径、PID、启动完成；只对本轮自有 PID 发正常退出，核对进程结束和正常保存标记。
- TC12（R06）：构建应用写入测试用 40 位提交号并本地签名，预期 plist 记录对应提交，codesign 严格校验通过；关于版本文案由 Bundle 版本和提交号产生，完整视觉检查另行执行，不以 plist 代替视觉验收。

## C 清理

- TC13（R05）：dist 内创建 PaperDock-0.1.0-trial-arm64-macOS26.zip 和 .zip.sha256、other.zip、同名解压目录以及指向其他文件的 0.1.1 ZIP 软链。安装成功后仅两个匹配的普通文件被删，其余内容保留。
- TC14（R05）：安装成功后旧应用临时备份被回收，不产生 ZIP；失败时沿 TC09 保留。

## D 第一部分的操作指引场景

以下是 Skill 语义推演，不执行真实便签功能变更，不将文案检查当作需求开发全链实测。

- TC15（R07）：输入“标题条再窄一点”，尚未明确宽或高；预期只问会改变结果的必要选择，不擅自改代码。补充“降低高度，其他不变”后，沿现有需求/用例确认，不重复问已定业务，也不让用户选择内部技术步骤。
- TC16（R08、R09）：只改标题条留白；预期构建并核对受影响状态的实际视觉，不能只以编译宣称通过，也不默认重跑全部存储套件。提供带明确 data-dir/evidence-dir 的候选命令，不单发双击应用链接；未启动候选前不关闭用户旧实例。
- TC17（R08）：改锁定下折展行为；预期选规则测试及相关操作链。改保存/数据格式时扩大到退出重开、失败保护与必要兼容验证；迁移授权未明则停止，不自行声明数据兼容。
- TC18（R10）：测试后修改源码、修 Review 问题或新增文档，预期重新取指纹后补受影响验证，不能倒填测试前指纹；仅文档变化无需机械重跑全部应用测试。
- TC19（R09、R10）：候选已准备但等待用户体验，或实际用例失败；预期保持待体验/未完成，不写本轮 ready.json，不继承历史交接。用户明确接受缺口时先同步范围，再核对交接条件；不能由 Agent 自己接受失败。
- TC20（R07、R10）：本轮仅改 Skill 文档，预期验证加载、相对路由、本地链接与上述场景，不构建应用。加载成功不等于需求到测试全链已验；不触发 deliver、提交、安装或历史包清理。明确调用第二部分才交给相邻 Skill。

## 执行与局限

自动化映射见 app/test_local_delivery.py；TC01–TC10、TC13–TC14 在真实临时 Git 和文件系统上执行，应用构建、GUI 启动使用模拟，不当作本机正式安装通过。TC11–TC12 使用项目独占构建与隔离数据，执行记录见 [implementation.md](implementation.md)。本轮不覆盖用户正式应用切换、真实保存失败弹窗、磁盘故障或完整关于面板视觉验收；没有独立审查结论。
