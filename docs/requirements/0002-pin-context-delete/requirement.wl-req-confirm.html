SEC 01 / 04

目标与已确认规则

用户希望防止便签被意外挪动或修改，并在全部列表直接删除指定卡片，不必先打开编辑器。两项需求已解释确认；用户选择整张锁定与重启保留，随后批准全部口径并要求开发。

R01：独立便签顶部增加钉住/解锁，状态可辨。钉住指整张便签锁定，不是现有普通窗口置顶。锁定期间禁止移动、缩放、修改标题/正文、操作待办、换色、收纳、删除；仅保留解锁入口。解锁恢复原有操作，不修改原内容。

R02：管理器对同一记录也遵守锁定，不可经另一编辑器、旧配色草稿、待确认删除等入口绕过；应用退出仍可正常保存退出。正常重开保持锁定状态和便签位置。锁定、解锁与位置记录不算内容修改，不迁日期分组。

R03：全部便签中对某张卡片右键出现删除选项，操作该卡片而非另一张当前选中记录。沿用现有确认与取消、移入回收站、恢复为收纳，无永久删除。锁定卡片删除置灰，先解锁再删除。列表空白不提供针对某张记录的删除。

现状与本次变化

E01静态源码可确认：当前正式0.1.0-local R1版本，浮窗有纸色/管理/收纳，没有钉住；窗口可移动缩放，未记录跨重启位置。管理列表卡片只含选择入口；删除在右侧编辑器。已核对Store、Model、Windows、Editor、Manager直接链路，不代表本轮已真人复验。

改前正式三栏实拍为上一轮独立者捕获的正式界面，非本轮最新画面；仅辅助说明三栏与工具区，无目标示意稿，本轮不制作新原型。

旧：打开独立便签 → 随时移动/编辑 → 关闭收纳
新：打开独立便签 → [新增]顶部钉住 → 整张锁定且另一入口也不可改
                                    ↓ 解锁
                                 恢复原操作
                                    ↓ 正常退出重开
                             [新增]锁定与位置保留

旧：全部列表选中卡片 → 右侧删除 → 确认 → 回收站
新：全部列表右键卡片 → [新增]删除菜单 → [保持]确认 → 回收站
                      └─ 锁定 → 删除置灰，不影响其他记录
