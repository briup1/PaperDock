## US08：锁定与恢复

### TC-015：顶部钉住与整张锁定

对应需求（Trace）：R01、R02、D01；优先级：P0。

**测试场景**：独立A便签钉住后限制操作，解锁恢复且B不受影响。

**测试数据**：公共A/B，A浮窗可见并移到屏幕中部，记录frame与内容时间。

**测试步骤**：

```text
1. A顶部点击钉住
   预期：显示已锁定/解锁入口；位置不跳，内容/待办/颜色/内容修改日期不变。
2. 在A分别尝试拖标题栏、拖缩放边、改标题/正文、待办改字/勾选/新增/移除、纸色/收纳及窗口关闭
   预期：移动/缩放无效，所有修改入口禁用或拒绝；A保持可见且原数据不变，仅解锁可用。
3. 操作B正文追加“带水”并移动一次
   预期：B正常可用，不因A锁定被全局锁住。
4. A点击解锁，移动/缩放后编辑标题正文，操作待办、配色、关闭收纳并找回
   预期：原有功能恢复，续写仍是同一A，无重复记录；仅内容改动更新日期。
```

### TC-016：跨入口与迟到草稿不可绕过锁定

对应需求（Trace）：R01、R02、D01；优先级：P0。

**测试场景**：浮窗与管理器同时打开同一A，旧操作不能在A钉住后提交修改。

**测试数据**：公共A/B；每个分支从未锁A开始，保存内容、颜色、日期与设置快照。

**测试步骤**：

```text
1. A浮窗钉住，在管理器选A
   预期：标题正文/待办/纸色/收纳/删除同样不可改；能辨认锁定，解锁仍可达。
2. 在管理器打开A配色预览但不应用，再从A浮窗钉住后尝试提交该旧草稿
   预期：A与已有颜色/新建配色设置不被旧草稿改变，不能因范围改固定/随机绕过此张锁定。
3. 独立分支先请求删除A，尚未确认时钉住A，再确认旧删除请求
   预期：A不进回收站、不收纳；B不变；取消旧请求也不改变数据。
4. A正文有一次尚未确认的中文组合输入时尝试钉住，再确认候选或继续输入
   预期：锁定生效后不再接受内容修改；锁定前有效正文保留，不提前把未确认候选伪作已保存，解锁后编辑可继续。
```

### TC-017：正常退出重开保留锁定和位置

对应需求（Trace）：R02、D02；优先级：P0。

**测试场景**：同一A钉住后正常退出重开，状态与位置一致。

**测试数据**：公共A/B；A位于当前主屏可用区域中部，记录A的ID/frame/原时间/正文/待办/颜色。

**测试步骤**：

```text
1. 移动A到可辨认位置，钉住，正常菜单退出并确认进程退出
   预期：保存成功；内容修改日期不因移动/钉住变更。
2. 同目录新进程重开，不预置或重置数据
   预期：同一A可见、保持锁定并位于原位置，正文/标题/待办/颜色/内容日期一致；B未被误锁。
3. 解锁A后编辑、正常退出重开
   预期：A保持解锁，原编辑正常保留，不因历史锁定永久只读。
4. 在隔离副本打开原0.1.0-local旧库，比较原有多记录/待办/设置
   预期：兼容读入且旧记录默认未锁；不能清空旧库。加载/升级失败可见报错并保留原件，不假成功。
```

## US09：列表直接整理

### TC-018：右键未选中卡片精准删除及取消

对应需求（Trace）：R03、D03；优先级：P0。

**测试场景**：全部便签选A时右键B，确认对象不串到A。

**测试数据**：未锁A/B均在全部列表，A为当前右侧编辑记录，记录两ID和原数据。

**测试步骤**：

```text
1. 右键B卡片，点击删除，再取消确认
   预期：菜单有删除；确认对象是B，A/B内容/可见状态/日期均不变。
2. 再右键B删除并确认
   预期：只有B移入回收站且其浮窗收起，A保留且不被误删；B原内容/日期保留。
3. 回收站恢复B
   预期：同一B恢复为收纳，原数据不变，无永久删除。
4. 在全部列表空白处右键
   预期：没有针对某张记录的删除，不以当前选择偷偷删除A。
5. 独立分支恢复未锁A/B，分别在正文末追加“共同检索Z219”，搜索该词，选A后右键匹配卡片B删除并确认
   预期：两卡片原先均匹配；仍以B的稳定ID为对象，不按结果索引或当前选择误删。
```

### TC-019：锁定卡片右键删除禁用与解锁恢复

对应需求（Trace）：R01、R02、R03、D01、D03；优先级：P0。

**测试场景**：A已锁定时，列表右键和旧请求均不允许删除。

**测试数据**：公共A钉住，B未锁。

**测试步骤**：

```text
1. 全部列表右键A
   预期：删除置灰不可选；A保持可见、内容和日期不变。
2. 右键B，取消或确认按TC-018执行
   预期：B菜单可用，不因A锁定置灰。
3. 解锁A后再次右键A，点删除并确认
   预期：删除恢复可用，只有A入回收站，不改B。
```
