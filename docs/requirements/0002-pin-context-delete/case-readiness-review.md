## 源码与方案一致性

- `app/Sources/Store.swift:11-21,58-62,114-130`：当前无锁/frame字段，目录已独占，Core Data关闭自动迁移；现有修改入口尚无锁保护。方案沿用旧SQLite模型、同目录按ID保存原子元数据，并在Store最终拒绝修改，符合当前事实与不破坏旧库的边界。
- `app/Sources/Model.swift:30-36,75-88`：删除已有pending ID；配色切到固定/随机时传给Store的noteID会变nil。方案要求保留草稿来源ID再校验、确认删除时重查锁状态，有必要，不能只灰按钮。
- `app/Sources/Windows.swift:29-49`、`app/Sources/Editor.swift:9-14,39`、`app/Sources/Manager.swift`：现窗口可缩放、关闭即收纳，正文仅防未确认组合输入，卡片没有右键删除。方案已覆盖窗口拦截、delegate保护和卡片ID菜单，未把既有能力误写成新增锁已实现。
- 方案元数据`critical_validation.status=verified`明确限定为既有共享ID/独占目录/禁迁移/窗口与删除路径的静态事实；正文明确新增锁及重启效果仍待实现验证。技术采用身份为开发委托，不冒充用户逐项看过方案。
