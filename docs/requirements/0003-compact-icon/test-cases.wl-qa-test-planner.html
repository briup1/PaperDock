TC-020：新建外框与协调布局

对应需求（Trace）：R01、R02；优先级：P0。

测试场景：在默认270×355pt新便签中查看浅/深色两状态待办及必要工具，管理器不缩小。

测试数据：公共A分别纸白和深灰；新建未记录frame。另空白新便签。

测试步骤：

1. 每种颜色独立分支新建一张浮窗，读取外框及内容区尺寸
   预期：新窗外框宽270、高355pt，包含标题栏；不是内容区270×355。空白同尺寸。
2. 查看标题、正文、日期、待办及钉住/纸色/管理/收纳
   预期：相较旧紧凑标题20/正文17pt同步缩小且可读，控件和留白协调，无按钮挤出/遮挡；顶部不显示桌面可见。
3. 打开同一A管理器
   预期：管理器仍原三栏尺寸/字号及可见/收纳标签，独立便签移除文案不误删管理器状态。
4. 将A换成长正文/8待办，滚动正文与待办并编辑末尾
   预期：内容可到达且修改同一A，非裁切隐藏，重要工具始终可用；单张缩放不让管理器字体变化。
5. 在未锁A上尝试移动/缩放/收纳找回，钉住后尝试同操作再解锁
   预期：未锁保持可用，锁后整张保护与顶部解锁可达，小尺寸不产生绕过或无法解锁。
