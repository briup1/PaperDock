# 需求0003：轻便的小便签与蓝色P图标

## 目标与新旧变化

当前用户觉得初始便签及字体过大，自行调小后要求按此作新建默认。协调者实际读取PID46879窗口149508得到外框宽270、高355pt；不是270×355像素或内容区大小。当前源码新窗口内容370×480pt，正文17pt、紧凑标题20pt，便签与管理器复用编辑器；顶部含桌面可见、钉住/纸色/管理/收纳。未运行新版，读取结果仅旧运行窗口实测与当前源码静态事实。

## 已批准规则

- R01：新建独立便签默认窗口外框270×355pt；标题、正文、待办、工具按钮与留白协调缩小，不以裁切内容达成小尺寸。字体保持层级可读，钉住/解锁等必要操作可达。用户手动缩放仍允许；不要求字号随每次窗口缩放动态变化。
- R02：只改独立便签；三栏管理器现有尺寸、字体和状态标签保持。独立便签顶部不再显示“桌面可见”；已钉住状态仍须可辨认，原收纳/置顶/输入行为不变。
- R03：采用用户已看过确认的assets/brand蓝色圆角底、白色P、浅蓝纸角图标作应用图标；构建产物包含有效Mac图标。图标素材不重新生成，不修改正在运行的旧包或系统图标缓存。
- R04：本增量保留0002整张锁定、跨入口保护、右键精准删除与原位置恢复。已有锁定/保存的窗口frame不得被新默认强行改成小尺寸；仅未记录尺寸的新窗口使用新默认。
