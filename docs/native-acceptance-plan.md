- **焦点**：用户在自己的普通外部应用输入源用例文字，便签部分重叠仍可见；再点击正式便签继续输入，分别记录落点和同 ID 内容。本应用 `isKey`、window level、自有演示窗口或静态图片只能辅助，不证明跨应用输入归属。
- **IME**：用户在正式正文实际启用中文输入法，输入候选、保持一次未确认组合、选择候选、退格并续写；记录候选过程/确认后文本和有无光标跳动、重复/提前提交。`insertText`、粘贴中文、发自造 NSEvent 均不证明 marked text 或真实输入法。日志不得把未确认候选当已保存正文证据。
- **边缘**：用户从外部普通应用焦点开始，不点击靠近右侧中段；离开、取消一次拖动、完整拖出松开、再次靠近。独立记录数量/ID，不能用菜单新建冒充拖动。
- 不写 UI 自动化权限脚本，不用 AppleScript/System Events、CGEvent 全局注入或 AX 请求替代真人。出现权限提示即停在该动作，标 BLOCKED；不引导用户本轮修改权限。
