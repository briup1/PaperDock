## 组件规则

### 状态修改与保存

```text
正文输入 → Store.edit(UUID) → 内存变更、dirty → save
层级切换 → AppModel/准备回调 → Store.setLayer → 保存内容 → 写布局 → 发布状态
```

Store/AppModel 沿 `@MainActor`；UI 经 UUID Binding/Store API 操作，不直写持久化或另存权威 notes。

| 动作 | 沿用写法 | 失败 / 反例 |
|---|---|---|
| 标题、正文、待办 | edit；值实际变化才更新 modified | 不用 arrange 绕日期 |
| 收纳、删除、恢复 | arrange；不改内容日期 | 不先 edit 再补旧日期 |
| 内容保存 | 内存先变更，再 save | 失败时 context.rollback，保留内存编辑及 dirty/error，可重试 |
| 高度/锁/折叠/层级/位置 | next → 原子写成功 → 发布；先 save 与否沿既有 set* | 失败返回 false；不先发布再回滚 |

```swift
store.edit(id) { $0.body = value }       // 正文修改
store.arrange(id) { $0.visible = false } // 收纳，不改日期
// 反例：store.edit(id) { $0.visible = false }
```

SQLite/JSON 无双文件事务，两类失败不能都当作 UI 回退。[Store](../../../app/Sources/Store.swift)：mutate/save/persistLayout。

### 锁定、身份与草稿

| 场景 | 必须保留 |
|---|---|
| 禁用按钮/隐藏菜单 | Store 最终变更边界仍检查锁定 |
| 删除确认 | pendingDelete 保存 UUID，confirmDelete 重查锁/删除状态；不用 selected 或数组位置替代目标 |
| 配色提交 | PaletteDraft.apply/Store.applyPalette 重查目标与来源 |
| 配色草稿 | hex/HSV、saved、scope；stage 不落盘，取消丢弃，apply 成功才关弹层 |
| 颜色/键鼠输入 | 沿 ColorValue 规范化；HSVControl 只改同一 draft，不改正式便签 |

实现：[Model](../../../app/Sources/Model.swift) 的 confirmDelete/PaletteDraft、[PaletteUI](../../../app/Sources/PaletteUI.swift)。

### 原生编辑与窗口联动

| 修改位置 | 沿用方式 / 禁止事项 |
|---|---|
| BodyCoordinator | 复用 NSTextView；marked text（未确认候选）不覆盖/提交（锁定同步可清除候选并回填已存正文）；仅内容不同时同步并约束选区。禁止 updateNSView 无条件 `view.string = body` |
| 折叠/层级/compact 添加 | 各自 prepare 检查**目标 panel** 候选，非别的 keyWindow；锁定不套同一准备逻辑 |
| 显示浮窗 | 每 UUID 一窗；orderFront 与 makeKey/activate 分离，显示不等于抢焦点 |
| placements 订阅 | Published 赋值前发事件；延到主队列读 Store 权威值 |
| 拖动/缩放 | 复用 floatingFrame/lockChanged，移动结束/live resize 结束保存；不在每次 mouse move 写全库 |
| compact 加待办 | `Todo.id → scrollTo → FocusState`；固定添加按钮在外层 ScrollView 外；保留管理器非 compact 分支 |

实现：[Editor](../../../app/Sources/Editor.swift) 的 synchronize/addTodoButton、[Windows](../../../app/Sources/Windows.swift) 的 prepare*/saveFrame。

### 解码与输入校验

布局仅**缺字段**兼容；null、错类型、未知 layer/version、非法 frame 报错保留原件。输入与 Store 双验有限数/范围；新字段补兼容/反例测试。

```swift
// 正例：缺 layer 才默认，错值继续抛错。
layer = c.contains(.layer) ? try c.decode(NoteLayer.self, forKey: .layer) : .floating
// 反例：layer = (try? c.decode(NoteLayer.self, forKey: .layer)) ?? .floating
```

实现：NotePlacement/NoteLayout、Store.loadLayout；字段/边界值见[数据模型](../wiki/数据模型.md)。

### 脚本与退出

| 位置 | 沿用方式 |
|---|---|
| [local_delivery.py](../../../app/local_delivery.py) | 标准库/argparse；selected_paths/no_symlink 校验，临时 index 算选定树；未选构建输入有改动时停止，不扩大选择集绕过 |
| Shell runner | `set -euo pipefail`、绝对输出路径、新证据目录；仅明确负向分支捕获非零，不吞异常造 PASS |
| 正常退出 | AppKit terminate → canTerminate/Store.save；失败拒绝退出，不发 kill；循环返回后由 main 交付退出码，不只看 normal-exit 标记 |

实现：[Application](../../../app/Sources/Application.swift) → [main](../../../app/Sources/main.swift)。参数/环境见[接口协议](../wiki/接口协议.md)；授权由[改动 Skill](../../../.agents/skills/paperdock-change/SKILL.md)/[交付 Skill](../../../.agents/skills/paperdock-local-delivery/SKILL.md)维护，不继承历史授权。
