# 工程结构

范围：原生应用、交付工具、原型与实验；状态：当前；依据：下列源码与构建脚本。

技术栈：SwiftUI + AppKit + Core Data；swiftc 直接编译，无 Swift Package/Xcode 工程。以下组织与命名为默认实践，非自动门禁。

### 架构分工

同一编译单元内按职责组织，不强制逐层调用。

| 文件 | 主要类型 / 职责 |
|---|---|
| [main.swift](../../../app/Sources/main.swift) | Options、main、ExportedState：参数、测试/夹具/导出分派、退出码 |
| [Application.swift](../../../app/Sources/Application.swift) | ApplicationController：应用装配、菜单/状态栏、管理/设置窗口、保存退出、GUI 证据 |
| [Manager.swift](../../../app/Sources/Manager.swift) | ManagerView/SettingsView：三栏管理、搜索/分组/删除确认、高度设置 |
| [Editor.swift](../../../app/Sources/Editor.swift) | NoteEditor：管理器/compact 共用编辑；NoteBody/BodyCoordinator：NSTextView、候选与选区；待办焦点、工具栏拖动 |
| [Model.swift](../../../app/Sources/Model.swift) | AppModel：选择、筛选、按 UUID 协调操作；PaletteDraft：配色草稿与提交 |
| [Store.swift](../../../app/Sources/Store.swift) | Note/Todo/ColorSettings、NotePlacement/NoteLayout；Store：目录锁、SQLite 三实体、布局 JSON、校验/查询/保存；schema 在代码中定义 |
| [Windows.swift](../../../app/Sources/Windows.swift) | NoteWindows/NotePanel：窗口恢复、限幅、锁/折叠/层级、拖动/缩放保存；Edge*：主屏边缘新建 |
| [Palette.swift](../../../app/Sources/Palette.swift) | ColorValue：颜色转换与文字色 |
| [PaletteUI.swift](../../../app/Sources/PaletteUI.swift) | PaletteView/HSVView/HSVControl：配色界面与原生键鼠控件 |

## 依赖与运行链路

### 组件依赖

| 组件 | 依赖对象 / 连接方式 |
|---|---|
| main | 创建 Store → ApplicationController |
| ApplicationController | 装配 AppModel、NoteWindows、ManagerView、SettingsView、边缘入口及窗口回调 |
| ManagerView / NoteEditor | AppModel、Store；正文/标题/待办可直接调 Store.edit，重试调 Store.save |
| NoteBody / BodyCoordinator | Store、NSTextView |
| AppModel / PaletteDraft | Store、数据类型；AppModel 经 floatingFrame、prepare*、lockChanged、show/hide 等回调连接窗口 |
| NoteWindows | AppModel/Store、NoteEditor、AppKit；订阅 placements，移动/缩放经 Store.updateFrame 保存 |
| PaletteView / HSVControl | PaletteDraft、ColorValue |
| Store | Core Data、文件系统、锁、ColorValue；因 NSRect 等类型使用 AppKit，不是纯 Foundation 层 |
| 程序测试 | 正式 Store/Model/控件；由 main/coreTests 或专项分派执行 |

### 运行单元边界

- **构建**：[build.sh](../../../app/build.sh) 通配编译 Sources、链接系统框架、复制 icns、生成 plist，不启动应用；[run.sh](../../../app/run.sh) 仅二进制缺失时构建，源码变更须显式重建。
- **交付**：[local_delivery.py](../../../app/local_delivery.py) → 临时源码构建 → [AppKit helper](../../../app/local-delivery-host.swift) 核对/正常退出 → 提交/安装/启动核验；不是产品运行依赖。授权与参数见[接口协议](../wiki/接口协议.md)。
- **原型/实验**：prototype 为 JS 内存演示、刷新重置；[native-spike](../../../experiments/native-spike/README.md) 有独立模型/数据/证据。均不复用正式 Store，不替代产品验证。

### 操作链路

```text
新建采购便签：入口 → AppModel.newNote → Store.create
  → showFloating → NoteWindows.show(UUID) → NoteEditor(compact)
输入正文/待办：delegate / Binding → Store.edit → 内存 dirty → Core Data save
折叠/层级：AppModel → prepare 回调（需要时）→ Store → 原子布局写入 → 窗口同步
锁定：AppModel.toggleLock → Store.setLocked → lockChanged
拖动/缩放结束：窗口事件 → Store.updateFrame
正常退出：canTerminate/save → AppKit stop → main 最终证据/退出码
```

## 常见改动落点

### 文件放置规则

已有功能沿上表职责修改；新增独立组件用 `app/Sources/{组件名}.swift`，不预设 controller/service/repository 分层。无固定拆分行数阈值，改变职责/依赖前先说明影响。

| 新增对象 | 放置 / 接入方式 |
|---|---|
| SwiftUI 视图、原生桥接 | Sources 同级文件，由 Manager/Editor/PaletteUI 组合 |
| 持久化类型与字段 | Store.swift 的类型、model/load/save 或布局解码/set*；不另建平行 schema |
| 窗口联动操作 | Model.swift 的 AppModel + Windows.swift 装配回调 |
| CLI 参数、fixture、导出 | main.swift 的 Options/seedFixture/ExportedState；运行观察在 Application.swift |
| 原生测试 / runner | `app/Sources/{主题}Tests.swift`，注册 [coreTests](../../../app/Sources/SelfTests.swift) 或专项分派；runner 用 `app/test-{主题}.sh` |
| 交付功能 / 测试 | app/local_delivery.py、local-delivery-host.swift、[test_local_delivery.py](../../../app/test_local_delivery.py)，同步项目交付 Skill |
| 需求 / 长期规则 | `docs/requirements/{编号-主题}/` / `docs/harness/rules/`、`wiki/`；见[开发流程规范](开发流程规范.md) |

### 命名规范

| 对象 | 格式 | 示例 / 例外 |
|---|---|---|
| Swift 类型 / 组件文件 | PascalCase；文件按主要组件/主题命名 | NoteEditor、Windows.swift；入口为 main.swift，不强制一类型一文件 |
| 方法 / 属性 / 回调 | lowerCamelCase | setLayer、heightDraft、prepareLayerChange |
| 目标标识 | UUID；参数沿 id / noteID / sourceNoteID | Note.id、Todo.id；不用标题/数组位置代替身份 |
| 测试文件 / 套件 | `{主题}Tests.swift` / 小写连字符 | NoteSettingsTests.swift / note-settings-compat |
| Shell runner | `test-{主题}.sh` | test-pin-delete.sh；通用入口 test.sh |
| Python 工具 / 测试 | snake_case / `test_` 前缀 | local_delivery.py / test_local_delivery.py |

### 关键结构约束

1. 持久化只经 Store API；禁止其他组件直接写 SQLite/布局文件。
2. Store 不依赖上层视图/窗口管理器；AppModel 不持有 NotePanel/NoteWindows 实例，通过回调连接。
3. 管理器与浮窗共用 Store/Note UUID；草稿与 savedFrame 不得成为第二套正式数据。
4. 锁校验保留在 Store 最终变更边界；窗口输入保护沿目标 prepare 回调，不假定锁定/折叠/层级检查相同。
5. 布局写成功后才发布状态；内容保存失败保留内存编辑，SQLite/JSON 无双文件事务。
6. Sources 只有一个顶层 main；原型、实验、交付 helper 不混编，测试复用正式实现。
7. 不为单一操作另起服务/存储层；数据字段与版本不得因命名整理擅自重命名。

### 修改与验证指导

| 改动 | 入口与关联组件 | 最小验证 |
|---|---|---|
| 按张整理操作 | Editor → AppModel → Store → NoteWindows；参考 setLayer | 扩展 NoteSettingsTests：成功、锁定拒绝、保存失败；补直接 GUI 用例 |
| 标题/正文/待办 | Note.title、Store.edit、BodyCoordinator、NoteEditor UUID Binding → 管理器搜索/分组与浮窗 | title/dates/query/editor；连续添加用 note-settings-todo-controls；候选与光标保护 |
| 高度/布局 | SettingsView → saveHeight → setDefaultHeight；NoteHeight、布局解码、NoteWindows.show/Store.setCollapsed | note-settings-rules/compat/controls、write→read；当前窗不跳、展开上沿/宽度不变、限幅与写失败 |
| 配色 | PaletteDraft、ColorValue、PaletteView/HSVControl → Store.applyPalette | palette/hsv、取消/无效输入、锁后旧草稿拒绝；默认改变不重染旧便签 |
| 参数/fixture/导出 | Options、seedFixture、ExportedState、Application.Observation → runner/导出消费者 | 非法参数、显式 data-dir、实际输出字段；导出未含 defaultHeight，不是全量备份 |
| 新组件/测试 | 按文件放置表接入现有界面/分派 | 构建、定向套件及新保护条件的拒绝分支 |
| 本地交付 | Python CLI、AppKit helper、项目 Skill | test_local_delivery.py 临时仓库模拟，不试装日常应用 |

具体命令、通过标准与真人 IME/跨应用/视觉验证边界见[测试规范](测试规范.md)；写法与失败机制见[编码规范](编码规范.md)。
