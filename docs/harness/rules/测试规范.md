# 测试规范

范围：原生应用、交付工具与文档验证；状态：当前；依据：app/test*.sh、Sources/*Tests.swift 与项目改动 Skill。

## 按改动选择验证

以下为默认实践，不要求每轮全跑。具体数据、操作与预期只维护在[对应需求用例](../../requirements/README.md)。

```text
改动 → 选直接受影响套件 → 成功与拒绝/失败分支
  → 涉及保存则跨进程读回 → 涉及交互则补真实操作 → 记录证据与缺口
```

| 改动 | 最小入口 | 补验条件 |
|---|---|---|
| 文档 / 引用 / Skill | 内容、链接、参数核对与接手推演；Harness 另做结构检查 | 行为描述有变才查直接实现；不启动应用、不跑 Swift 套件 |
| 标题 / 日期 / 搜索 / 控制器 | `title`、`dates`、`query`、`controller` 中相关项 | 跨正文/窗口边界加对应套件与交互 |
| 正文 / 待办 / 输入法 | `editor`；连续添加用 `note-settings-todo-controls` | 真人候选、光标与焦点；程序 marked text 不替代真人 IME |
| 配色 | `palette`、`hsv` | 取消、无效值、锁后旧草稿拒绝；改保存加 `write→read→read-random` |
| 钉住 / 删除 | `test-pin-delete.sh`，程序控件加 `--controls` | 菜单、拖动、焦点实际操作；锁后最终拒绝 |
| 字号 / 裁切 / 图标 | `compact-*`、`test-compact-icon.sh` 相关项 | 展开/折叠/锁定状态视觉；旧测试含 355pt 假设，先核断言适用性 |
| 高度 / 层级 / 折叠 / 布局格式 | `note-settings-rules`、`note-settings-compat`、`note-settings-controls`；`note-settings-write→note-settings-read` | 旧字段、null/错误类型、越界；frame/焦点变化补滚轮、Tab、跨应用 |
| 内容保存 / 退出 | 相关规则、`bad-store`、`write→read→read-random`；退出用 `test.sh --gui-only` | 保存失败、正常退出重开；结果门改动补缺失完成结果的拒绝反例 |
| Python 本地交付 | `test_local_delivery.py` 临时仓库 / 模拟应用 | 真实 helper、退出或安装另核授权，不从模拟推断通过 |

新增保护条件至少验证一种应拒绝输入/操作。故障注入只用合成库；解除 hook 后重试不证明任意真实 I/O 故障可恢复。数据格式变化另核兼容与迁移授权。

## 执行入口与证据

### 命令形状

示例的 `example-new` 换成本轮唯一名称，执行前确认输出目录不存在。runner 自行构建，勿在同目录预构建；`build.sh`、`test.sh` 不都会拒绝已有构建目录，须人工核对。

```bash
ROOT=/Users/ziyun/workdir/self_project/PaperDock
# 仅构建，再用此次二进制定向验证。
B="$ROOT/artifacts/developer/example-new/build"
bash "$ROOT/app/build.sh" "$B"
"$B/PaperDock.app/Contents/MacOS/PaperDock" --test note-settings-rules --data-dir "$ROOT/artifacts/developer/example-new/data-rules"

# runner：证据在前、构建在后；会开 GUI 窗口。
bash "$ROOT/app/test.sh" "$ROOT/artifacts/acceptance/example-new/evidence" "$ROOT/artifacts/acceptance/example-new/build"

# 使用已管理的 Python 3.12.9，不下载运行时或安装依赖。
uv run --no-python-downloads --no-project --python 3.12.9 python "$ROOT/app/test_local_delivery.py" -v
```

| 入口（路径均须绝对） | 范围 / 注意事项 |
|---|---|
| `test.sh [--gui-only] 证据目录 构建目录` | 默认基础套件＋跨进程读回＋GUI；`--gui-only` 仅 GUI。**不含 note-settings 系列**，须显式选跑 |
| `test-pin-delete.sh [--controls] 证据目录 构建目录` | 钉住/删除；拒绝已有输出目录 |
| `test-compact-icon.sh 证据目录 构建目录` | compact/控件/图标与结果门反例；拒绝已有输出目录 |

新增套件注册到 [coreTests](../../../app/Sources/SelfTests.swift) 或 [noteSettingsTests](../../../app/Sources/NoteSettingsTests.swift)，并纳入本轮选择；旧 runner 成功不代表新套件已跑。

### 结果门与证据区别

- **程序套件**：断言完成且退出码 0；编译成功不算测试通过。
- **GUI probe**：wait=0、启动 PID 已结束，且 `gui/normal-exit.txt`、`gui/gui-result.json` 均存在；JSON 的 pid 匹配、status=passed、completed=true。
- **结果门反例**：`bash "$ROOT/app/test.sh" --check-gui-result /absolute/evidence-parent PID WAIT_STATUS` 不启动应用，应拒绝仅 exit=0 / normal 标记而缺完成结果的输入。
- **真实界面**：关键状态保留可辨识视觉证据；程序断言、NSButton.performClick、NSView.cacheDisplay 内容图、系统截图、真人反馈分开标注。内容图无系统遮挡/窗口框；程序编辑不证明真实键盘归属、IME 或物理点按。

失败修复后用新目录补验，保留原失败，不用 normal 标记覆盖失败结果。

## 环境与副作用边界

| 边界 | 要求 |
|---|---|
| 环境 | [README](../../../README.md) 记录 Apple Silicon、macOS 26.5.1、Swift 6.3.3 CLT；plist 最低 26.0 不证明所有 26.x 可用 |
| 数据 | 每套显式 `--data-dir`，用项目内独占新绝对目录；仅跨进程读回在前一写进程退出后复用同轮数据。程序检查绝对路径/目录锁，不保证目录属于本轮 |
| 实例 | 自有探针正常保存退出并核对 PID；用户持续体验实例明确交接，不悄悄关闭，不停止未知/日常实例 |
| 授权 | 不复制日常库、不试迁移真实数据、不改权限/安装依赖/覆盖运行应用；提交、安装与交付沿[项目改动 Skill](../../../.agents/skills/paperdock-change/SKILL.md) |

本机入口卡 `.harness-local/testing.md` 必须忽略且未跟踪，只登记“去哪测、用谁测”。缺卡先核验忽略状态，再建地址表与“入口、环境、账号、密码”四字段 JSON：环境为已核实的完整 `file://` URL；原生应用/原型无登录，账号密码为空并注明不适用，不创建账号。候选未核实则待确认，不把默认构建产物当本轮候选；启动参数与交接由项目 Skill 维护。
