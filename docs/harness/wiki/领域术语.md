# 领域术语

范围：PaperDock 易混淆名称及代码对应；状态：当前；依据：Store、Model、Editor、Windows 与项目交付 Skill。

## 术语与名称对应

下表为当前实现。操作预期见[业务模型](业务模型.md)，字段/存储见[数据模型](数据模型.md)。

| 名称 | 代码对应 | 不可混用点 |
|---|---|---|
| 便签 / 待办 | `Note.id` / `Todo.id`、`Note.todos` | 待办是便签内的有序子项，不是另一张便签；两者各有 UUID，标题/数组位置不是身份 |
| 自动 / 手动标题 | `Note.title` / `manualTitle` | 手动非空优先；否则由正文/待办取净化后前 5 个字素，全空为“空白便签”；不是字节截断 |
| 内容修改 / 整理 | `Store.edit` / `arrange`、布局 `set*` | 标题/正文/待办有效变化更新 `modified`；颜色、收纳、删除恢复、窗口整理不更新 |
| 管理器 / 独立便签窗 | `ManagerView` / `NotePanel`、`NoteEditor(compact: true)` | 同一 Store、同一 Note UUID；compact 是编辑器布局，不是第二份内容 |
| 桌面可见 / 已收纳 / 回收站 | `Note.visible`、`deleted` / `NoteFilter` | 收纳只隐藏；删除为软删除；恢复后仍已收纳且 ID 不变，不是立即重开窗口 |
| 钉住（锁定） / 浮顶 / 沉底 | `NotePlacement.locked` / `NoteLayer` | 钉住限编辑/整理但可解锁；floating/desktop 是层级。沉底为普通窗口下一级，不是收纳或锁定 |
| 折叠显示 / 展开矩形 | `NotePlacement.displayedFrame` / `frame` | 27pt 折叠条不是持久高度；frame 保持展开矩形，移动按当前上沿反推 |
| 全局便签高度 | `Store.defaultHeight`、`NoteHeight` | pt 值，下次打开/展开生效，当前窗不跳；190 仅新库/缺字段初值，不覆盖已有值；折叠条不受展开高度下限约束 |
| 配色草稿 / 暂存 / 应用 | `PaletteDraft` / `stage()` / `apply()` | 预览/收藏先留草稿，取消丢弃，apply 才提交；`saved` 为收藏、`added` 扩随机池、`fixed` 固定以后用色 |
| 输入法组合文字 | `hasMarkedText()`、`BodyCoordinator` | marked text 未确认，不能当已确认正文；程序组合态检查不是真人输入法验证 |

## 易混淆边界

沉底 → 收纳 → 找回：`setLayer(.desktop)` 仅改层级 → `stash(UUID)` 隐藏 → `show(UUID)` 重开同一记录。钉住时整理受限；改动保留 Store 最终锁校验，不仅禁用按钮，见[编码规范](../rules/编码规范.md)。

交接名称也不等价（提交/安装仍须本轮授权）：

| 名称 | 证明什么 / 不能推出什么 | 详细规则 |
|---|---|---|
| candidate / 标准 ready | 候选版本 / 指定文件树、指纹和测试声明的交接记录。手工 manifest/hash 不是 ready；`approve` 不跑测试、不核验声明、不安装 | [改动 Skill](../../../.agents/skills/paperdock-change/SKILL.md)、[交付 Skill](../../../.agents/skills/paperdock-local-delivery/SKILL.md) |
| approved / verifying / done / launched | 需求批准 / 执行验证中 / 执行完成 / 程序启动；启动不等于全验通过 | [开发流程规范](../rules/开发流程规范.md) |
| normal-exit / GUI passed | 正常保存退出标记不等于 GUI 通过；runner 还核对本 PID 的 passed、completed、退出码 0 及进程结束 | [test.sh](../../../app/test.sh) |
| 内容图 / 系统截图 | `cacheDisplay` 只绘自有视图内容；系统图可包含窗框/遮挡，但单图不证明完整交互 | [测试规范](../rules/测试规范.md) |

prototype 网页、native-spike 实验与正式应用的模型/证据不能混用，见[工程结构](../rules/工程结构.md)。
