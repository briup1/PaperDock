# 业务模型

范围：原生便签能力与状态；状态：当前；依据：Store、Model、Editor、Windows 及既有需求。

## 角色与能力边界

当前 Mac 使用者随手记录文字/待办，桌面独立显示，三栏管理器集中搜索、收纳和找回。无账号、云同步、协作或网络服务。

下文是实现事实，非验收/授权。原型、实验及环境边界见[工程结构](../rules/工程结构.md)。

## 能力与流程

### 新建与桌面找回

```text
菜单/状态栏/管理器新建，或主屏右缘拖出
  → AppModel.newNote → Store.create（统一取纸色、保存空记录）
  → 清搜索、切全部、选中 UUID → NoteWindows.show → 一 ID 一张独立窗
```

| 场景 | 规则 |
|---|---|
| 空库 | 不自动创建便签；新建保存失败遵循下文保存规则 |
| 边缘拖出 | 主屏右缘中段 2×130pt，靠近展开 24pt；左拖≥40pt、主屏内松开才新建。单击/取消/不足阈值不新建，拖动中不收回 |
| 找回/输入 | “显示到桌面”复用原 UUID；显示不主动抢键盘焦点，点击编辑区才输入 |

### 文字、标题与待办

```text
输入采购便签正文/标题/待办 → 按 UUID 更新 Store.edit
  → 更新内容日期并保存 → 标题、摘要、搜索和日期分组同步变化
浮窗底部“添加待办” → 检查本张锁/候选 → 新 Todo UUID → 滚动定位并聚焦
```

| 对象 | 规则与例外 |
|---|---|
| 标题 | 手动标题非全空白时优先，清空恢复自动标题；自动取正文+待办去行首列表标记/空白后前 5 个 Swift Character，空为“空白便签” |
| 正文候选 | 输入法候选未确认时不保存、不回填正文；钉住例外见下文 |
| 连续待办 | 以 Todo UUID 而非行号定位；浮窗下沿固定入口可连续添加，候选未确认则提示拒绝、不转焦点；管理器沿自身布局 |
| 保存失败 | 保留内存；展开区可滚到错误/“重试保存”，折叠条可查看错误；重试调 Store.save |

**内容日期只随标题/正文、待办文字/勾选/增删变化**，配色、移动/缩放、收纳、删除/恢复及下文整理操作均不更新。

### 管理、搜索与删除恢复

```text
筛选+搜索 → Store.results → 内容日期倒序（同刻按 UUID）→ 本地自然日分组
全部列表右键卡片/管理器编辑栏删除 → pendingDelete(目标 UUID) → 确认时重新校验
  → 回收站：deleted=true、visible=false，收起窗口 → 恢复：已收纳，不自动弹窗
```

| 场景 | 规则 |
|---|---|
| 筛选 | 全部、桌面可见、已收纳均排除已删除；回收站只含已删除，内容只读 |
| 搜索/选择 | 搜标题+正文+待办，忽略大小写/变音符；编辑后失配保留编辑器并提示，不跳记录。切筛选清选择 |
| 分组 | 今天/昨天/日期按本地自然日，每 30 秒刷新标签 |
| 收纳 | 浮窗×/关闭即隐藏，保留内容、UUID、折叠状态 |
| 删除 | 右键仅“全部”卡片提供；用被点 UUID，不用当前选择。取消不变，锁定/已删除拒绝；无永久删除/自动清理 |

### 纸色与未来新建规则

```text
打开纸色/默认设置 → PaletteDraft 临时预览、暂存
  → 应用时校验颜色和目标当前状态 → Store.applyPalette → 保存成功才关闭
取消/×/Escape → 丢弃草稿，不保存
```

| 选择 | 改变什么 | 不改变什么 |
|---|---|---|
| 只改当前 | 当前便签纸色 | 未来模式、随机池 |
| 以后固定 | 未来新建取 fixedColor | 已有纸色、原随机池 |
| 加入随机/切回随机 | 切随机模式；勾选 addToPool 才把当前色去重加入池 | 未勾选不加色；不重染旧便签 |

随机池为内置六色+主动加入色，允许连续同色。暂存也属草稿；无效 hex 禁应用，选色盘/清空可恢复。提交时再次拒绝已锁/已删除目标；保存失败不承诺内存/磁盘一起回滚。

### 钉住、折叠、高度与层级

```text
本张工具栏/设置 → AppModel 核验 → Store 保存必要内容、写布局
  → 布局写成功才发布 → NoteWindows 同步窗口；失败保留旧整理状态
```

| 能力 | 生效规则 | 保护与例外 |
|---|---|---|
| 钉住 | 整张锁定，不是浮顶；管理器同 ID 也只读 | 禁编辑、移动/缩放、纸色、折展、层级、收纳/删除；保留解锁、失败提示与正常退出保存。正文未确认候选不保存，锁定同步可清除候选 |
| 折叠 | 原宽/原色/同上沿的 27pt 标题条；拖后按新上沿展开，采用当前全局高度 | 布局保存展开尺寸，不把 27pt 当展开高度；折叠前遇本张未确认候选则拒绝，锁定不可折展 |
| 全局高度 | 设置中保存；默认 190pt，有限数字 175…1000，保留 177.5 等精度 | 当前窗不跳；新开/收纳后重开/重启/展开生效，含锁定窗重开。宽度/字号/纸色/日期不联动；屏幕限幅不改设置值 |
| 高度失败 | 非法/写失败保留草稿和旧值 | 已存值不被默认 190 覆盖；修正后重存 |
| 按张层级 | 默认浮顶 `.floating`；沉底为普通窗口 level−1 | 不改可见性/默认纸色；锁定、已删除/收纳或本张候选未确认拒绝切换；level 数值不证明跨应用效果 |

### 启动、保存与退出失败

```text
绝对数据目录 → 独占目录锁 → SQLite 模型/记录校验 → 布局校验 → 恢复可见窗
内容变更 → 内存 dirty → Core Data save
  ├─ 失败：rollback context，保留内存 dirty/error → 用户重试
  └─ 成功：清 dirty/error
正常退出 → endEditing → canTerminate/save
  ├─ 失败：提示并拒绝退出，保留编辑
  └─ 成功：停止 AppKit 循环 → main 写最终证据/真实退出码
```

- 同目录第二写入进程拒绝；坏库/布局、未知版本报错保留原件，不清空重建或自动迁移未知模型。
- 布局失败不发布新状态；移动/缩放保存失败恢复上次位置尺寸。
- SQLite 与布局无整体事务，不承诺异常退出零丢失；格式、兼容与恢复边界归[数据模型](数据模型.md)。
