# 数据模型

范围：持久数据、内存状态与交付记录；状态：当前；依据：下列源码定义。

## 数据所有权总览

| 数据 | Owner / 写入入口 | 保存位置 / 使用者 |
|---|---|---|
| 便签、待办、配色 | [Store.swift](../../../app/Sources/Store.swift)：类型、model/load/save | `PaperDock.sqlite` 及辅助文件；管理器、编辑器、配色弹层共用 |
| 按张布局、全局高度 | Store：NotePlacement/NoteLayout、set*、updateFrame | 同目录 `NoteLayout.json`；窗口、设置界面读取 |
| 编辑草稿与界面状态 | [Model.swift](../../../app/Sources/Model.swift)：AppModel、PaletteDraft | 仅内存，提交才调用 Store |
| 窗口与焦点 | [Windows.swift](../../../app/Sources/Windows.swift)：NoteWindows/NotePanel；AppKit | 仅内存，不是持久布局 |
| 交付记录 | [local_delivery.py](../../../app/local_delivery.py) | `.work/local-delivery/`，非产品数据 |

按本机目录隔离，无账号/租户表。无参数使用当前用户 `Application Support/PaperDock`；开发/验证须显式指定项目内独占绝对目录，不共写日常库。

## 对象与状态

### 便签与配色：SQLite

```text
采购便签 Note(UUID) ← Todo.noteID（Todo[] 以 position 保序）
                  ← JSON 中同 UUID 的 NotePlacement
全局 ColorSettings → 单条 Settings(id=default)
```

`Store.model()` 动态定义 `PaperDock.1`，无 `.xcdatamodel`；三实体均以 id 唯一、属性非 optional。Todo 用 UUID 字段关联，不是 Core Data relationship。

| 对象 | 保存内容 / 派生值 |
|---|---|
| Note | 手工标题、正文、修改时间、可见/删除标志、颜色；title/summary 计算得到，不另存 |
| Todo | 自有 UUID、文本、完成状态；save 写入 Int64 position，删除已移出内存列表的 Todo 行 |
| ColorSettings / Settings | 固定色模式、颜色；added/saved 在 SQLite 内为 JSON 字符串。随机池=内置色+added 去重排序，收藏 saved 不自动入池 |

- edit 更新内容日期，arrange 不更新；无永久删除 Note 入口。删除/恢复等标志转换与操作条件由[业务模型](业务模型.md)负责。
- **内容先改内存再保存**：成功清 dirty/error；失败只回滚 Core Data context，不回退 Store.notes/settings，保留 dirty/error 供重试。配色 apply 同理，界面变色不等于落盘。
- load 拒绝重复身份、孤儿 Todo、无效记录/颜色；坏库或模型不兼容报错保留，不清空重建；自动 SQLite 模型迁移关闭。
- Store 为 `@MainActor`、context 用主队列；`.paperdock.lock` 非阻塞独占 flock 随 Store 存活，拒绝第二写入者。锁只保护该目录入口，不可借目录别名并写同库。

### 布局与高度：NoteLayout version 1

顶层含 version、按 UUID 字符串索引的 notes、defaultHeight；NotePlacement 保存锁定、折叠、层级和**展开矩形**。完整字段以 Store 的 Codable 定义为准。

| 项目 | 默认、兼容与拒绝条件 |
|---|---|
| defaultHeight | 默认 190pt；有限数字 175…1000pt，保留小数（如 177.5）；只缺字段时补默认，null/错类型/越界拒绝 |
| collapsed / layer | 缺字段分别补 false / floating；null、错类型、未知 layer/version 拒绝 |
| 身份与锁定 | 非法/重复 UUID、找不到 Note 的 placement 拒绝；locked=true 仅允许未删除且 visible 的 Note |
| 展开矩形 | 数值有限；坐标绝对值≤100000，宽 270…100000、高 175…100000。历史矩形高度上限不同于全局输入的 1000 |
| 显示矩形 | 折叠为同上沿 27pt；moved 换回展开矩形。打开/展开取当前全局高度；屏幕限幅只改显示，不因加载限幅重写保存值 |

```text
折叠采购便签：目标/锁校验 → save 内容 → 原子写布局 → 发布 placements → 窗口同步
拖动结束：updateFrame → 只写布局、不改日期 → 失败退回 savedFrame
设置高度：校验草稿 → 原子写布局 → 发布 defaultHeight（当前窗口不跳）
```

`setLocked/setCollapsed/setLayer` 实际变更时先保存内容；前置条件各不相同，以各方法为准，不合并成同一检查。布局成功才发布元数据，失败保留旧值并报错。

SQLite/JSON **无双文件事务**，可能内容已保存而布局失败。加载拒绝保留原文件，不删 JSON 解错；不自动迁移/重写旧 JSON，无 v2 迁移。真实数据迁移、备份、回退须另行授权。

### 内存、窗口与导出

| 状态 | 生命周期 / 限制 |
|---|---|
| 选择、搜索、pendingDelete | 随进程结束，不持久化 |
| 高度/配色草稿 | saveHeight 成功才改高度，失败留草稿；配色取消丢弃，apply 才调 Store |
| panels / opened / savedFrame | 按 UUID 缓存窗口；重复 show 不重套高度，hide 清 opened，重开再应用高度；savedFrame 用于移动失败回退 |
| 正文候选与焦点 | [BodyCoordinator](../../../app/Sources/Editor.swift) 不保存未确认输入法候选；Note.visible 不等于窗口已显示、成为 key 或取得 firstResponder |
| [ExportedState](../../../app/Sources/main.swift) | 仅 notes/settings/placements，**缺 defaultHeight**，不是全量备份/恢复格式 |
| [Observation](../../../app/Sources/Application.swift) | 启动/退出的进程、内容、错误及窗口等观察，不是备份 |

导出通过 Store 获取目录锁，不并写、不擅自复制日常库；参数见[接口协议](接口协议.md)。

### 候选与交付交接

`snapshot` 绑定 HEAD、候选 tree、paths 的 SHA256 指纹；`approve` 核对后原子写 `ready.json`，含验证说明、局限和兼容声明，但不执行测试或证明兼容。`deliver` 再核交接及构建/提交树；源码变动不自动刷新 ready，历史 manifest/安装结果不替代验收。

字段、拒绝条件与授权由[本地交付 Skill](../../../.agents/skills/paperdock-local-delivery/SKILL.md)负责；加载不等于执行授权，交付锁不代替数据锁。

| 改动 | 定义 / 直接消费者 | 验证重点 |
