## 通用约定

- 本地用户/文件权限/数据目录是边界，无账号、Token、HTTP。
- 路径用绝对值；交付 `--paths` 用逐个仓库相对文件。开发用项目内独占数据/新证据，不共用日常库、覆盖历史或强杀实例。
- UUID 标识目标；Void/UUID/窗口变化不证明落盘，内容失败看 dirty/error，false 不保证内存回滚。
- 示例不授予执行/安装权限；候选直跑明确二进制，不双击或 `open -a`。

## 接口与消息条目

### 原生程序 CLI

```text
Options 校验 → --test（优先，完成即退出）
  否则：Store（持目录独占锁）→ seed → export → 按组合退出或启动 GUI
```

| 参数 | 条件 / 结果 |
|---|---|
| `--data-dir ABS_DIR` | 无开发参数可省略，默认当前用户 Application Support/PaperDock；以下任一参数出现时必须显式提供 |
| `--test NAME` | [coreTests](../../../app/Sources/SelfTests.swift) 及专项分派；成功0，未知名称/失败1，不进正常应用 |
| `--seed-fixture standard\|history\|empty-fixed` | 空 notes 库写合成数据；empty-fixed 只写配色。非空/未知名称/保存失败拒绝；内容见 seedFixture |
| `--export ABS_FILE.json` | 父目录须存在；输出 notes/settings/placements，pretty/sorted、日期 ISO8601；未含 defaultHeight，不是全备份 |
| `--evidence-dir ABS_DIR` | 创建目录、写观察/内容缓存图/退出证据；程序不拒绝旧目录，执行者须选新目录 |
| `--quit-after SECONDS` | 正的有限秒数；计时后请求正常保存退出，不是强退或真人 IME 验证 |
| `--gui-test` | 无值开关，另须 evidence-dir；执行正式 GUI probe，写 gui-result.json，保留真实退出码 |

未知/缺值/相对路径/非法计时/漏目录：stderr、退出1；Store 打开失败保留原数据，GUI 路径另弹错。解析器不核目录归属。

export 无 gui-test 时写完退出；仅 seed 时退出，带 evidence/quit-after/gui-test 则进入应用。常用 seed+export；同目录导出也占锁，须等 GUI 正常退出。

夹具/导出例：先构建此候选、创建父目录，确认 data 为空、目录本轮独占。

```bash
CASE=/Users/ziyun/workdir/self_project/PaperDock/artifacts/developer/example-new
"$CASE/build/PaperDock.app/Contents/MacOS/PaperDock" \
  --data-dir "$CASE/data" --seed-fixture standard --export "$CASE/initial.json"
```

### 模块调用与窗口回调

`Editor/Manager/Application → AppModel/Store → 窗口回调`；AppModel、Store 在 MainActor 上消费，持久化只经 Store。

| 调用 | 返回 / 副作用与拒绝条件 |
|---|---|
| `newNote() → UUID` | create 后重置筛选/搜索、选中并开窗；create 保存失败仍返回内存 UUID |
| `show/stash/select/changeFilter → Void` | show 拒绝无目标/已删，stash 拒绝锁；显示/收纳通知窗口，改筛选清选择 |
| `Store.edit(id, closure)` / `arrange(id, closure)` | Void；无 ID/锁定/无变化不改；edit 更新 modified，arrange 不更新；有效变化立即 save，失败保留内存 |
| `toggleLock(id) → Bool` | 锁定前只结束当前 key 窗非候选文本编辑；Store 重查目标，锁定要求可见/未删；无有效 frame/保存失败拒绝 |
| `toggleCollapsed(id) → Bool` | 锁定/不存在/已删拒绝；仅收起前 prepareCollapse；展开用默认高度 |
| `toggleLayer(id)` / `setLayer(id, NoteLayer) → Bool` | 锁定/不存在/已删/不可见拒绝；同层级直接 true，否则 prepareLayerChange → Store.setLayer |
| `heightDraft` → `saveHeight() → Bool` | 175…1000pt 有限数；非法/写失败保留草稿与旧值、给 feedback；成功不改当前窗，下次打开/展开生效 |
| `requestDelete(id)` → `confirmDelete(Bool)` | 设 pendingDelete，确认重查锁/已删/身份；取消不删，最后清 pending；成功标删除并隐藏。`restore(id)` 恢复为收纳 |
| `PaletteDraft.apply() → Bool` | 重查颜色、旧草稿源目标未锁/未删，按 scope 提交；false 不关弹层，保存失败保留内存变更 |
| `Store.save()` / `canTerminate() → Bool` | 成功清 dirty/error；失败 rollback Core Data context，保留内存 notes/settings，设 dirty/error；canTerminate 委托 save |

NoteWindows 装配 weak self 回调；缺 prepare/无目标 panel 不额外拒绝，模块测试不证明输入保护。

| 回调 | 返回 / 关键差异 |
|---|---|
| `floatingFrame(UUID) → NSRect?` | 当前显示 frame；无值可用已存 placement，否则布局操作可能失败 |
| `prepareCollapse(UUID)` / `prepareLayerChange(UUID) → Bool` | 只看目标窗，有 marked text 拒绝并设 error，否则 endEditing 后通过 |
| `prepareTodoAddition(UUID) → Bool` | compact 添加前查候选，拒绝不追加；不强制 endEditing；通过后 edit 追加 Todo UUID、滚动/聚焦，非保存回执 |
| `lockChanged(UUID) → Void` | 布局成功后同步窗口，placements 订阅也下一轮同步；布局写失败不发布新值，内容/布局无共同事务 |

```swift
let changed = model.setLayer(id, .desktop) // 目标校验、候选保护、保存、窗口同步
// 不可替代：panel.level = ... 只改窗口，不更新正式状态。
```

### 退出、观察与 GUI 结果

```text
正常退出请求 → 结束 field edit → canTerminate/save
  失败：弹窗、terminateCancel，保留编辑
  成功：stop 主循环、仍返回 terminateCancel → main.finishTermination → exit(0/1)
```

不改成 AppKit 自带 exit0 吞失败，不用 kill 代替保存退出。

| 输出 | 消费规则 |
|---|---|
| launch.json / observed.json / exit.json | 含 pid/version/directory、notes/settings、selected/filter/query、dirty/error、windows（visible/key/level/frame）、screen；非备份或完整布局导出 |
| manager-content.png | NSView 内容缓存图，非系统截图 |
| normal-exit.txt | 保存退出流程标记，probe 失败也可能存在，不能单独当通过 |
| gui-result.json | `{pid,status,completed,failure}`；须同 PID、passed、completed=true，同时 wait=0、进程已结束且有 normal-exit |

证据写失败/probe 未完成退出非零；结果门见 test.sh/check_gui_result，边界见[测试规范](../rules/测试规范.md)。

### 构建与测试 runner

脚本位于 app/；ABS_* 须替换绝对目录。runner 自行构建，不预构建同一路径。

| 调用 | 输出 / 失败与覆盖边界 |
|---|---|
| `bash build.sh [ABS_OUT]` | 默认 app/build，创建/覆盖、stdout 输出二进制路径；不启动/安装/签名。Bundle ID=local.paperdock.app；版本常量不标识源码 |
| `bash run.sh [程序参数]` | 仅默认二进制缺失才构建，然后 exec；不检查源码更新，候选须显式重建 |
| `bash test.sh [--gui-only] ABS_NEW_EVIDENCE ABS_BUILD` | 旧证据拒绝，build 不查新旧；非 gui-only 跑核心9套及串行 write/read/read-random，之后 GUI；不含 note-settings 系列 |
| `bash test.sh --check-gui-result ABS_PARENT PID WAIT_STATUS` | 只读 ABS_PARENT/gui，不启动；格式错退出64，结果不通过返回1 |
| `bash test-pin-delete.sh [--controls] ABS_NEW_EVIDENCE ABS_NEW_BUILD` | 两目录须不存在；规则/跨进程读写，controls 加隐藏控件；非真实拖动/右键/IME |
| `bash test-compact-icon.sh ABS_NEW_EVIDENCE ABS_NEW_BUILD` | 两目录须不存在；控件/重启 frame/图标/结果门反例；非完整 GUI/Dock |

runner 用 set -e 中止，格式/旧目录拒绝退出64，日志 commands.log/套件日志；保留失败。改参数/套件同步消费者、测试规范及 [app README](../../../app/README.md)，单个 runner 非全覆盖。

### 本地交付 CLI

交接归[改动 Skill](../../../.agents/skills/paperdock-change/SKILL.md)；提交/安装/清理须明确调用[本地交付 Skill](../../../.agents/skills/paperdock-local-delivery/SKILL.md)，只加载不授权。

| 子命令 | 输入 / 返回与副作用 |
|---|---|
| `fingerprint --paths FILE…` | 文件可含已跟踪删除；拒绝目录/绝对/越界/软链、父仓库、分离 HEAD、未完 Git 操作/冲突、未选构建输入；JSON 为 head/tree/paths/fingerprint，临时 index 不动真实暂存区 |
| `approve --paths FILE… --fingerprint HASH --automated TEXT --developer TEXT --limitations TEXT --data-compatible` | 指纹须一致、三段非空声明、兼容断言；原子替换 STATE/ready.json，不测试/核声明/安装；待体验/失败不填通过 |
| `deliver -m MESSAGE --data-dir EXISTING_ABS_DIR [--old-pid PID]` | ready 提供 paths；message 非空，data 含 PaperDock.sqlite、不在安装/STATE/dist 内；实例须唯一/PID 匹配，路径属项目 artifacts、app/build 或安装目标；拒绝选定文件部分暂存 |

STATE=`.work/local-delivery`；三个子命令都持独占锁，fingerprint 也可能创建目录/lock。最小指纹例（此处不执行）：

```bash
UV_PYTHON_DOWNLOADS=never uv run --no-project --python 3.12.9 python \
  /Users/ziyun/workdir/self_project/PaperDock/app/local_delivery.py fingerprint --paths README.md
```

```text
deliver：核 ready/指纹/数据/暂存 → 临时源码构建与 helper → 核实例/源码未变
  → 只提交选定文件、核 tree → stamp commit + ad-hoc 签名
  → 正常退出旧实例 → 同卷替换当前用户 Applications/PaperDock.app
  → 同 data-dir 启动，核 PID/路径/finishedLaunching/Bundle commit
  → 删临时旧包、限定 ZIP 清理 → last-result.json + stdout JSON
```

失败 stderr/退出1并报阶段，用法错2；不回退 Git/数据。退出30秒/启动15秒超时即停、不强杀；替换失败尝试恢复旧包，恢复不成或启动失败保留旧包。成功 launched 非完整验收。

成功后仅清 dist 直接普通非软链 `PaperDock-数字.数字.数字-trial-arm64-macOS26.zip[.sha256]`，不递归、不清 artifacts；不推送/发布。验证：[test_local_delivery.py](../../../app/test_local_delivery.py)、[0006 记录](../../requirements/0006-local-delivery/implementation.md)。

### AppKit helper

Python 构建本次 helper 后调用，只处理 Bundle ID=local.paperdock.app。

| 调用 | 返回 / 约束 |
|---|---|
| `HELPER list` | JSON 数组：整数 pid、executable 路径（系统未提供时为空串）、finishedLaunching Bool |
| `HELPER quit PID EXECUTABLE` | PID 与当前路径须同时匹配；调用 NSRunningApplication.terminate；`{"requested":true}` 只表示请求发出 |

身份改变、拒绝、用法错误均 stderr/退出1；无强退接口。Python 再等至无匹配实例，超时失败；不得复用历史 PID。
